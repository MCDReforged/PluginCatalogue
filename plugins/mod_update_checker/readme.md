### Introduction

Scans every jar in the server's `mods/` folder and checks it against Modrinth by file hash: which mods have newer versions, which have no build for the current loader / game version, and which cannot be identified. Read-only by default — downloading, install-on-stop and old-backup cleanup are opt-in.

Full documentation (Chinese): [README.md](https://github.com/LifeSci-Craft/MCDR-ModUpdateChecker/blob/main/README.md)
